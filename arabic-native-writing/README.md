# مهارة «الكتابة العربية الأصيلة»

مهارة (Skill) لـ Claude تجعل النص العربي يُقرأ كأنه كُتب بالعربية من أول سطر، لا كأنه فُكّر بالإنجليزية ثم تُرجم.

**المشكلة:** النماذج تترجم ترجمة جيدة، لكن الأمثلة والاستعارات وبناء الجملة وإيقاعها تأتي من الإنجليزية. فتخرج عبارات مثل «لدينا ثلاثة خيارات على الطاولة»: كلمات عربية ومعنى مستعار.

## ماذا تفعل

- **قواعد الصياغة:** خمس خطوات: حدّد القارئ والمستوى، ابنِ المعنى أولًا، ابنِ على قوالب عربية، افحص، ثم سلّم.
- **ثلاثة مستويات:** فصحى بيضاء (الأصل)، فصحى بنفَس سعودي، ومحكي أبيض مكتوب عند الطلب. وقاعدة ذهبية: **التحرير لا يغيّر المستوى**؛ من أعطاك نصًّا محكيًّا فلهجته هي المطلوبة، ولا يُصلَح فيه إلا الكاليك والأخطاء الصريحة.
- **مراجع (`references/`):** سياقات الكتابة، فهرس أساليب بقوالبها، بنك عناوين وافتتاحات وإقفالات، جداول تعريب، شواهد، صور من بيئة القارئ، وحالات رجعية.
- **فاحص آلي (`scripts/calque_check.py`):** يلتقط 56 نمطًا (regex) من الكاليك والأصدقاء الكاذبين في الجدول، إضافة إلى الإيقاع المبتور وتكرار «لا… بل» وإفراط أدوات الربط، ثم يقترح بديلًا.

## التثبيت

**Claude (claude.ai):** نزّل المستودع كملف ZIP، ثم الإعدادات ← القدرات ← المهارات ← رفع مهارة. (تتطلب خطة تدعم المهارات وتفعيل تنفيذ الشيفرة؛ راجع مركز مساعدة Claude إن اختلفت القوائم.)

**Claude Code:**

```bash
git clone <رابط-المستودع> ~/.claude/skills/arabic-native-writing
```

## الفاحص

```bash
python3 scripts/calque_check.py نص.txt            # تقرير نصي
python3 scripts/calque_check.py نص.txt --json     # أو JSON
```

يحتاج Python 3 فقط، بلا مكتبات. نتيجة «لا ملاحظات» تعني خلوّ النص من الأنماط المعروفة لا أنه عربي أصيل؛ القراءة البشرية تبقى لازمة.

### التعلّم من تصحيحاتك

```bash
python3 scripts/add_correction.py --wrong "يضرب على الوتر الصحيح" --fix "يصيب موضع الحاجة" --why "استعارة منقولة"
python3 scripts/add_correction.py --list      # ما سجّلتَه
python3 scripts/add_correction.py --export    # صفوف جاهزة لإرسالها إلينا
```

تُحفظ التصحيحات في `~/.arabic-native-writing/corrections.csv` (يمكن تغيير المسار بالمتغير `ARABIC_NATIVE_CORRECTIONS`)، خارج مجلد المهارة، فلا تضيع عند تحديثها. يقرؤها الفاحص تلقائيًّا بعد القواعد الأساسية، وتحمل علامة «غير مراجَع». يلتقط الفاحص العبارة نفسها لا تصريفاتها ولا الأنماط المشابهة (استعمل `--regex` للتصريف). وفي تطبيق claude.ai لا تُحفظ الملفات بين المحادثات، فلا تعمل هناك.

### فرض الفحص تلقائيًّا (Claude Code)

المهارة تعليمات، ولا تستطيع وحدها منع النموذج من خطأ. أقوى ضمان أن يُفرض الفحص من خارجه: خطّاف (hook) يشغّل الفاحص بعد كل كتابة لملف نصي، فإن وجد خطأً أعاد التقرير إلى Claude ليصلحه. مثال في `.claude/settings.json` (لم يُجرَّب بعد في بيئتك؛ جرّبه على ملف تجريبي أولًا):

```json
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Write|Edit",
      "hooks": [{
        "type": "command",
        "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.txt|*.md) python3 ~/.claude/skills/arabic-native-writing/scripts/calque_check.py \"$f\" --strict ;; esac"
      }]
    }]
  }
}
```

رمز الخروج 2 يوصل رسالة الأخطاء إلى Claude. في تطبيق claude.ai لا تتوفر الخطّافات، وتبقى بوّابة الفحص في خطوات المهارة هي الضمان الوحيد.

## حدود يجب أن تعرفها

- **طبقة النجدية رقيقة.** ما هو مؤكَّد نجديًّا قليل ومعلَّم بـ[مؤكَّد]، وما سواه خليجي عام أو [مقترح]. المحكي الأصيل يحتاج تصحيحات متحدثين حقيقيين.
- **الكثافات انطباعية** من قراءة نصوص رصينة، لا إحصاء آلي. وعتبات الفاحص تقديرات عملية.
- **الأمثلة مؤلَّفة** وعلامتها [مؤلَّف]، وليس في المستودع نص منسوخ. أما الشواهد (آيات وأحاديث وأبيات وأمثال) فراجعها قبل النشر الرسمي.
- الفاحص لا يميّز العربية الأصيلة من الفصحى السليمة المترجمة؛ قيمة المهارة في القوالب والصور والمستوى، لا في الفحص.

## المساهمة

أفضل ما يُحسّن المهارة: **عبارة مترجمة رأيتَها وطريقة أصلية لقولها**. أضِف صفًّا إلى `references/07-calques.csv` بالأعمدة نفسها (النمط، سبب الخطأ، البديل الفصيح، البديل المحكي)، أو افتح Issue بالجملة قبل الإصلاح وبعده. وكل لفظ محكي تؤكده كمتحدث يُضاف بعلامة [مؤكَّد].
