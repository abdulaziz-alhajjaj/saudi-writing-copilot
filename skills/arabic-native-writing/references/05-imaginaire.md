# 05 — الصور والاستعارات: من بيئة القارئ

## الفرق الجوهري

الكاتب العربي الجيد لا يرمي استعارات متفرقة. يختار **صورة حاكمة** من بيئة قارئه ويمدّها في النص (عنوان، افتتاح، وسط، ختام). أما النموذج المترجم فيرمي استعارة إنجليزية جاهزة في جملة («رجّع الميزانية للغرفة») بلا جذر في وعي القارئ.

في النصوص المحلَّلة: التمييز بين **الاستعارة المفردة** (كلمة: «الصقر»، «المعجزة») و**الاستعارة التمثيلية** (صورة كاملة: قافلة تسري ليلها حتى يلوح الصبح). والثانية أقوى وأبقى.

## صور رُصدت في النصوص المحلَّلة

| الصورة | ما تقوله |
|---|---|
| الصقر والقنص | القوة والبصيرة والحزم |
| السُّرى في الليل ثم الصباح | نضال طويل ينتهي ببلوغ الغاية |
| العنقاء | الانبعاث والتجدّد |
| المعجزة | خرق المألوف |
| الجبل الراسخ (طويق) | الثبات أمام الصعاب |
| الإسفنج والمسام | استقبال الماء بدل مقاومته |
| الأفلاج والخطارات | معرفة تراثية قديمة بالماء |
| المحرّر الماهر | النسيان ينتقي ويحذف ويُبقي |
| مفاوضة النسيان وأسلحة الإنسان | الذاكرة صراع وتفاوض |
| المطبخ مملكة صغيرة | المساحة تكتسب معناها بالاختيار |
| اللغة الجديدة للقوة | التقنية لغة يتقنها من بدأ مبكرًا |
| الرهان والأصول والاستثمار | الموهبة رأس مال يتراكم |
| الكتاب موعد وحبيب قديم | القراءة لقاء |

## صور مقترحة (لم تظهر في النصوص المحلَّلة؛ اقتراح مني)

| الصورة | ما تصلح له | محاذير |
|---|---|---|
| البحر والغوص واللؤلؤ | الصبر والمخاطرة والعائد غير المضمون، الاستثمار طويل المدى | قريبة من الخليج والشرقية خاصة |
| النخلة والتمر | الجذور والنمو البطيء والثمرة الموسمية | |
| البئر والواحة | الموارد النادرة وحسن إدارتها | |
| المطر والوادي والسيل | الفرصة المفاجئة وسرعة الاستفادة منها | |
| الزرع والحصاد | الجهد والنتيجة المؤجلة | قد تبدو مألوفة جدًّا |
| المجلس والقهوة | الحوار والضيافة وصناعة القرار الجماعي | |
| الخيمة والوتد | الأساس والثبات | |
| الحداء والقافلة | العمل الجماعي والسير الطويل | |

## قواعد

1. **صورة حاكمة واحدة** لكل نص (أو لكل قسم طويل). تتكرر ثلاث أو أربع مرات بعبارات مختلفة.
2. **من بيئة القارئ**: ما يعرفه ويحسّه، لا ما يقرؤه في ترجمات.
3. **تخدم الفكرة**: اسأل أولًا: ما الذي تضيفه الصورة إلى الحجة؟ إن لم تضف فاحذفها.
4. **لا تمزج صورتين متنافرتين** في جملة واحدة.
5. **الصورة تُختبر بالقارئ**: هل يفهمها دون شرح؟ هل يشعر أنها له؟

## تحويل الاستعارات الإنجليزية

| الإنجليزية | تجنَّب | استعمل |
|---|---|---|
| in the room / at the table (حيث يُتّخذ القرار) | «في الغرفة»، «على الطاولة» | «في دائرة القرار»، «ضمن الحسبان»، «في حساب [فلان]»؛ و«على طاولة الحوار» مستقرّة في السياق التفاوضي |
| elephant in the room | «الفيل في الغرفة» | «المسكوت عنه»، «الحقيقة التي يتجاهلها الجميع» |
| move the needle | «تحريك الإبرة» | «يُحدث أثرًا ملموسًا» |
| silver bullet | «رصاصة فضية» | «حلّ سحري»، «عصا سحرية» |
| low-hanging fruit | «الثمار المتدلية» | «أيسر المكاسب»، «ما هو في المتناول» |
| game changer | «مغيّر قواعد اللعبة» | «نقلة نوعية»، «يغيّر المعادلة» |
| deep dive | «غوص عميق» | «قراءة معمّقة»، «وقفة مطوّلة» |
| pain point | «نقطة الألم» | «ما يؤرّق العميل»، «موضع المعاناة» |
| on the same page | «على نفس الصفحة» | «متفقون»، «على رأي واحد» |
| take a step back | «خطوة إلى الوراء» | «نعيد النظر»، «نتأمل من بعيد» |
| unlock value | «فتح القيمة» | «إطلاق الإمكانات الكامنة»، «تفعيل» |
| leverage | «رافعة» | «الإفادة من»، «توظيف»، «استثمار» |
| ecosystem (مجازًا) | «النظام البيئي» | «المنظومة»، «البيئة» |
| bandwidth (طاقة الشخص) | «عرض النطاق» | «طاقتي»، «وقتي المتاح» |
| runway | «المدرج» | «المدى المتاح قبل نفاد المال» |
| headwinds | «رياح معاكسة» (شائعة في الاقتصاد، مقبولة) | «ظروف معاكسة»، «عقبات» |
| journey (تحوّل ونمو) | «رحلة التحوّل» (كثيرة) | «مسار»، «مرحلة»، «طريق» |

**القاعدة العامة:** إن لم تجد في الجدول ما تحتاجه، فاسأل: ما **المعنى** وراء الصورة؟ ثم قله بالعربية كما يقوله كاتب عربي، أو اختر صورة من بيئة قارئك.
